# Manhwa Reader — Discord-бот для чтения манхвы

Вы загружаете главы, участники сервера читают их прямо в Discord (кнопки ◀ ▶, выбор главы, переход на страницу), бот помнит, где кто остановился, а тайтлами можно делиться карточкой с кнопкой «Читать».

> Загружайте только то, на что у вас есть права (свои работы, лицензия, разрешение автора).

## Установка

1. Создайте приложение на https://discord.com/developers/applications → **Bot** → **Reset Token** (скопируйте токен).
2. На той же странице включите **Message Content Intent** (нужен для пакетной загрузки глав).
3. **OAuth2 → URL Generator**: scopes `bot` и `applications.commands`; права: View Channels, Send Messages, Embed Links, Attach Files, Add Reactions, Read Message History. Откройте ссылку и добавьте бота на сервер.
4. На компьютере/сервере (нужен Python 3.10+):

```bash
pip install -r requirements.txt
cp .env.example .env      # впишите DISCORD_TOKEN (и желательно DEV_GUILD_ID)
python bot.py
```

Бот должен работать постоянно, поэтому лучше держать его на VPS или домашнем сервере.

## Команды

**Для всех**
- `/library` — список тайтлов, выбор → карточка с кнопками «Читать» и «Поделиться»
- `/read title [chapter]` — читать; без номера главы продолжит с последнего места
- `/share title [chapter]` — опубликовать в канале карточку тайтла или главы с кнопкой «Читать»

**Для админов** (право «Управление сервером» или ID в `ADMIN_IDS`)
- `/title_add`, `/title_edit`, `/title_delete` — управление тайтлами (название, описание, жанры, статус, обложка)
- `/chapter_add title number file` — глава из ZIP/CBZ архива с картинками
- `/chapter_begin` → отправка картинок в канал → `/chapter_end` — для глав, которые не влезают в лимит файла Discord; бот ставит ✅ на каждое принятое сообщение
- `/chapter_cancel`, `/chapter_delete`

## Как это работает

- Длинные вебтун-полосы автоматически режутся на страницы (по пустым промежуткам между панелями, если они есть). Размер страницы настраивается через `SLICE_RATIO`.
- Все изображения конвертируются в JPEG и ужимаются до безопасного для Discord размера.
- Читалка видна только тому, кто её открыл (ephemeral), поэтому каналы не засоряются.
- Кнопки «Читать» в расшаренных карточках продолжают работать после перезапуска бота.
- Данные лежат в папке `data/` (`manhwa.db` + страницы). Делайте её резервную копию.
